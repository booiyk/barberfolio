Barberfolio

Pencatatan barbershop per cabang — pola Propfolio, objeknya cabang.

Khusus owner Pencatatan keuangan semua cabang — hanya untuk kamu sebagai pemilik usaha.

Barberfolio — data tersimpan lokal di browser ini (localStorage, kunci barberfolio-v1). Buka file index.html apa adanya, tanpa build dan tanpa internet. Versi produksi memakai Supabase — lihat supabase/schema.sql.
